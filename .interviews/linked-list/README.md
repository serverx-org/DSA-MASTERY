# Linked List Interview Problems

This folder contains common linked list problems frequently asked in technical interviews. These implementations help you prepare for coding interviews by providing solutions to classic linked list challenges.

## What's Included

This collection focuses on essential linked list operations and algorithms that are commonly tested in technical interviews at top tech companies.

### Available Problems

- **Merge Sorted Lists** (`merge_list.cpp`) - Merge two sorted linked lists into one sorted list
- **Find Middle of Linked List** (`middle_of_linked_list.cpp`) - Find the middle node using the two-pointer technique
- **Remove Nth Node from End** (`remove_nth_node_from_end.cpp`) - Remove the nth node from the end of the list
- **Reverse Linked List** (`reverse_list.cpp`) - Reverse a singly linked list iteratively and recursively
- **Reverse Nodes in K-Groups** (`reverse_node_in_kGroup.cpp`) - Reverse every k consecutive nodes in the list

## How to Use These Resources

1. **Study the Problem**: Understand what each problem is asking before looking at the solution
2. **Try Solving First**: Attempt to solve each problem on your own before reviewing the provided code
3. **Analyze Time/Space Complexity**: Consider the efficiency of each solution
4. **Practice Variations**: Many of these problems have variations that might appear in interviews
5. **Code in Your Preferred Language**: While implementations are in C++, try coding them in your preferred language

## Interview Tips for Linked List Problems

1. **Draw It Out**: Visualize the linked list and the operations you need to perform
2. **Handle Edge Cases**: Consider empty lists, single-node lists, and boundary conditions
3. **Two-Pointer Technique**: Master this technique as it's used in many linked list problems
4. **Practice Memory Management**: Be careful about pointer manipulation to avoid memory leaks
5. **Explain Your Approach**: Walk through your solution step-by-step during interviews

## Common Patterns

- **Two Pointers (Fast/Slow)**: Used for finding middle, detecting cycles, etc.
- **Dummy Node**: Helpful for handling edge cases in insertion/deletion problems
- **Recursion vs Iteration**: Many problems can be solved both ways
- **In-place Operations**: Modifying the list without extra space
